GymRat (*Diploma Project*) – a hybrid mobile fitness application for personalized AI-powered workout programs and progress tracking.

---

### Technologies
- **frontend:** React Native Expo, JavaScript, Redux Toolkit;  
- **cloud services:** Firebase (Authentication, Firestore, Realtime Database, Storage);  
- **ai/ml:**  
  - personal fine-tuning of Meta Llama 2 (7B) via QLoRA on custom workout dataset;  
  - 4-bit quantization with BitsAndBytes;  
  - deployed and hosted on Hugging Face Inference Endpoints;
- **apis:** ExerciseDB on RapidAPI.

---

### Testing
- **unit & component:** Jest, jest-expo, @testing-library/react-native, react-test-renderer, snapshot tests;  
- **integration:** Redux ⇆ UI, navigation flows, Firebase service calls;  
- **e2e:** real-user flows (login → workouts → calendar) on Android devices;  
- **external services:** Postman collections for RapidAPI; inference-endpoint validation via widget or cURL.
